# Nawaf Rubayan · Portfolio

My personal portfolio website – built with React and Tailwind CSS.  
It includes my CV, projects, skills, and contact information.

🔗 **Live site:** `https://Nawaf-Rubayan.github.io/portfolio/`  


---

## 📁 Files

- `index.html` – the portfolio page  
- `cv.pdf` – my CV (downloadable)  

---

## 🚀 How to run locally

1. Download both files (`index.html` and `cv.pdf`) into the same folder.
2. Open `index.html` in your browser.

---

## 🌐 Deployment

This site is deployed via **GitHub Pages**.  
Just push the files to a public repository and enable Pages in Settings.
